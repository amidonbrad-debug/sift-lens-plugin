# Sift Lens — install (about 2 minutes, on your own accounts)

1. **ChatGPT on the web.** Settings → Plugins → Developer mode → turn it on → Create.
   Name `Sift Lens`, URL `https://sift-lens.amidonbrad.workers.dev/mcp`, authentication none. Create.
   Then in any chat: `+` → enable Sift Lens → ask "What stands out on tonight's board?"
   The board renders in the chat; tap a company for its record and chart.

2. **Optional, ChatGPT desktop or Codex.** Adds the Sift skill so the assistant knows the rules.
   Plugins → Add → Add a marketplace → `https://github.com/amidonbrad-debug/sift-lens-plugin.git`,
   branch `main`, sparse paths empty → Browse directory → Sift → Sift Lens → Install.
   Or: `codex plugin marketplace add amidonbrad-debug/sift-lens-plugin`

3. **The Lens web page.** https://sift-lens.amidonbrad.workers.dev — enter the token the Sift owner gives you.

Nothing here is a recommendation; the connector is read-only.
